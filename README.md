Project 3: Local Network-Based Influence Prediction


Predicting how globally influential a person is in a network using only localized information (e.g., an individual's immediate friends and friends-of-friends) instead of requiring full network visibility.


Version 1: https://drive.google.com/file/d/17vOcBlgxCVf3czU2FOgB0HKQMgef6FaW/view?usp=drivesdk
Version 2: https://docs.google.com/document/d/14fVTygblyGgiliWsKWdGtG43FxuEs5YDGQQWSuWJN4s/edit?usp=drivesdk

Topics: Local Network Structure, Neighborhood Embeddings, Ego-Networks, Structural Profiling, Multitask Learning, Feature Engineering on Graphs, Clustering on Engineered Features, Link Prediction, Local Influence Forecasting, Inter-node Similarity, Node Centrality, Community Detection vs Clustering, Graph Robustness, Dimensionality Reduction, Unsupervised Evaluation Metrics, Model Transferability, Algorithmic Scalability

Python Libraries: NetworkX, python-igraph, PyCaret, scikit-learn, pandas, numpy, scipy, PyTorch Geometric, NetworKit, CDlib
